# 🧴 Automatic Sensor Dispenser (ESP8266 / C++)

Автоматический бесконтактный сенсорный дозатор (для жидкого soap, антисептика или воды) на базе микроконтроллера **Wemos D1 mini (ESP8266)**. Устройство определяет поднесенную руку с помощью ультразвукового датчика **HC-SR04** и активирует привод (сервопривод или помпу) для подачи заданной порции, сопровождая процесс световой (RGB LED) и звуковой (Buzzer) индикацией.

---

## 📌 Особенности проекта

* **Бесконтактное срабатывание:** измерение расстояния в реальном времени с защитой от ложных срабатываний и дребезга.
* **Дозированная подача:** гибкая настройка времени работы помпы / угла поворота сервопривода (порция) и задержки (cooldown) между выдачами.
* **Светозвуковая индикация (RGB LED + Buzzer):**
  * 🔵 **Синий (Standby):** режим ожидания, готов к работе.
  * 🟢 **Зеленый + Звук (Dispensing):** успешное обнаружение руки и выдача порции.
  * 🟡 **Жовтый (Cooldown):** пауза после выдачи, предотвращающая повторную подачу.
* **Аппаратная оптимизация под ESP8266:**
  * Учтены особенности boot-пинов (`D3`, `D8`), что гарантирует **стабильную прошивку платы без необходимости отключать компоненты**.

## 🛠️ Компоненты и распиновка (Pinout)

### Необходимые детали:
1. **Wemos D1 mini** (ESP8266) — 1 шт.
2. **HC-SR04** (Ультразвуковой датчик) — 1 шт.
3. **Исполнительный механизм** (один из вариантов):
   * Сервопривод **SG90** (для механического нажатия на дозатор).
   * Помпа 5V / Реле / Мосфет **IRF520** (для качки жидкости).
4. **RGB LED** (с общим катодом/анодом) + резисторы (220 Ом) — 1 шт.
5. **Пьезопищалка (Buzzer)** — 1 шт.
6. Макетная плата (Breadboard) и провода DuPont.

### Схема подключения:

| Компонент | Пин на модуле | Пин Wemos D1 mini | GPIO (ESP8266) | Примечание |
| :--- | :--- | :--- | :--- | :--- |
| **HC-SR04** | `TRIG` | **D5** | GPIO14 | Импульс запуска |
| | `ECHO` | **D6** | GPIO12 | Эхо-импульс |
| | `VCC` | **5V / VIN** | 5V | **Строго 5V** для стабильной работы |
| | `GND` | **GND** | GND | Общий минус |
| **Привод (Servo / Relay)** | `Signal` | **D2** | GPIO4 | Сигнал управления (PWM / Relay) |
| | `VCC` / `GND` | **5V / GND** | 5V / GND | Питание привода |
| **RGB LED** | `Red (R)` | **D1** | GPIO5 | Красный канал |
| | `Green (G)`| **D4** | GPIO2 | Зеленый канал |
| | `Blue (B)` | **D0** | GPIO16 | Синий канал |
| **Buzzer** | `Signal` | **D7** | GPIO13 | **Поддерживает `tone()`** |
| | `GND` | **GND** | GND | Общий минус |
